# MuseMate Development Guidelines

## Git Rules

1. Do not push directly to main.
2. Create a feature branch for new work.
3. Make small, meaningful commits.
4. Push your branch regularly.
5. Use Pull Requests for merging into main.
6. Review code before merging.

## Development Rules

1. Understand the code before committing it.
2. Test new functionality.
3. Do not commit API keys or passwords.
4. Do not commit large datasets or generated model files.
5. Follow the agreed MusicalContext schema.
6. Document important architectural decisions.
